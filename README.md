# Patton AI

Patton AI (PattonAI) is a Service-Disabled Veteran-Owned Small Business (SDVOSB) in San Juan, Puerto Rico. We build Patton Hive, battle management command and control (BMC2) software that commands existing drones, ground robots and vessels as heterogeneous swarms under human command authority, through TAK/ATAK (Cursor on Target) and MAVLink/ROS 2 bridges.
